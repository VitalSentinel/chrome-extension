# Security policy

## Supported versions

Only the latest release published in the Chrome Web Store and Edge Add-ons receives security
fixes. Older versions update automatically.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Email **security@vitalsentinel.com**. Please do not open a public issue for a security problem.

Include what you found, the steps to reproduce it, the extension version
(`chrome://extensions`) and the browser version. A proof of concept helps; please keep it to
your own accounts and test sites.

What to expect:

- We acknowledge your report within 3 working days.
- We confirm whether it is a vulnerability and share a fix plan within 10 working days.
- We credit you in the release notes when the fix ships, unless you prefer not to be named.

## Bug bounty

There is no bug bounty programme. We do not pay for reports, but we are grateful for them
and credit reporters who want it.

## Scope

In scope: this extension's code, its handling of OAuth tokens, the data it stores in the
browser, and what it sends to VitalSentinel.

Out of scope: the VitalSentinel web app and API (report those to the same address, they are
handled separately), third-party sites the extension analyses, and issues that need a
compromised browser or operating system.

## Safe harbour

We will not take legal action against research done in good faith that respects user
privacy, avoids service disruption, and gives us reasonable time to fix the problem before
disclosure.
