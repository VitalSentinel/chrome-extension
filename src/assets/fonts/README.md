# Fonts

Latin subsets of the app's fonts, bundled so the popup never loads anything remote:

- `inter-latin-wght-normal.woff2` – Inter (variable weight) by Rasmus Andersson, SIL Open Font License 1.1
- `space-grotesk-latin-700-normal.woff2` – Space Grotesk Bold by Florian Karsten, SIL Open Font License 1.1
- `space-mono-latin-400-normal.woff2` – Space Mono Regular by Colophon Foundry, SIL Open Font License 1.1

Copied from the `@fontsource` packages; to update, reinstall them and copy the same files.
